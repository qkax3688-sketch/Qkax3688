병원 관리자용 설정 안내 (처음 설치 시 한 번만 읽어주세요)

1. 이 파일을 환자용 컴퓨터에 저장한 뒤, Chrome 또는 Edge 브라우저로 열어주세요.

2. 검사 카드 운영 방식: 검사마다 4자리 코드를 정해 라미네이팅된 카드에 인쇄해두고, 접수 시 담당자가 해당 검사 카드를 환자에게 건네줍니다. 환자는 화면에서 그 코드를 입력해 해당 검사만 진행하고, 끝나면 카드를 검사대 앞 반납함에 넣습니다. 환자는 검사 목록을 직접 고르지 않으므로 잘못된 검사를 할 위험이 거의 없습니다.

2-1. 현재 등록된 검사 코드표 (완전 무작위 4자리)
7254 = IPSS (국제전립선증상점수)
4831 = NIH-CPSI (만성 전립선염 증상 점수표)
7103 = OAB-V8 (과민성 방광 증상 점수표)
6320 = ICIQ-SF (국제 요실금 설문지)
5315 = IIEF-5 (국제 발기능 측정 설문지)
6074 = PEDT (조루증 진단 설문지)
4473 = ADAM (남성 갱년기 설문지)
6933 = AMS (남성 노화 증상 설문지)
9441 = FSFI (여성 성기능 장애 설문지)

2-2. ⚠ 임상 사용 전 확인 필요: 위 검사들의 문항·채점 방식·중증도 구간은 공개된 의학 문헌을 바탕으로 최대한 정확하게 구성했지만, IIEF-5·ADAM·OAB-V8·FSFI 채점 구조는 원문을 검색으로 대조 확인했고, NIH-CPSI의 중증도 구간(경증/중등도/중증 경계)과 AMS의 17개 문항 원문·소척도 배정, ICIQ-SF의 세부 문구는 참고용으로 작성한 부분이 있습니다. 실제 환자 진료에 사용하시기 전에 병원에서 이미 쓰고 있는 공식 한국어판 설문지(원문)와 문항·배점을 반드시 대조 확인해 주시기 바랍니다. 특히 FSFI는 6개 영역에 서로 다른 가중치(x0.6/x0.3/x0.4 등)를 곱하는 복잡한 채점 방식이라 오류 위험이 가장 높으니 각별히 확인해 주세요. IIEF-5, FSFI 등 일부 설문지는 원저작권자의 저작권으로 보호되는 표준화된 검사 도구이므로, 병원에서 임상 또는 상업적으로 사용할 권한이 있는지도 함께 확인하시길 권장합니다.

3. 새 검사를 추가하려면 이 파일을 텍스트 편집기로 열어 TEST_REGISTRY 부분을 찾으세요. 그 안에 예시 템플릿 주석이 있으니 그 형식을 복사해서 새 코드(다른 검사와 겹치지 않는 4자리 숫자)와 문항 내용을 채워 넣고, 새 카드를 출력하시면 됩니다.

4. 맨 아래 "관리자 설정 열기"에서 비밀번호를 입력하면 검사 결과 상세, 엑셀 복사, 공용 폴더 저장 설정 버튼이 나타납니다. (기본 비밀번호는 파일 내부 코드 ADMIN_PASSWORD에서 변경할 수 있습니다.)

5. 관리자 패널에서 "공용 폴더 저장 설정" 버튼을 눌러 병원 공용 폴더(네트워크 드라이브 등)를 한 번 선택하면, 그 다음부터는 환자가 검사를 마칠 때마다 결과가 자동으로 그 폴더에 저장됩니다. 검사별로 {검사명}_결과기록.csv 파일이 각각 누적되고, 환자별 상세 결과가 담긴 개별 텍스트 파일도 함께 저장됩니다. 엑셀 붙여넣기용 제목행은 "이름 | 검사일시 | 1번 항목 | 2번 항목 … | 총점 | 중증도" 순서입니다.

6. 브라우저 보안 정책상, 브라우저를 새로 켤 때마다 자동저장 권한을 한 번 다시 확인해야 할 수 있습니다. 이는 정상입니다. Safari, Firefox 등 폴더 자동저장을 지원하지 않는 브라우저에서는 대신 파일이 다운로드되며, 이 경우 브라우저의 기본 다운로드 폴더를 병원 공용 폴더로 지정해 두면 됩니다.

7. 공용 폴더 경로를 코드에 메모해두고 싶다면 HOSPITAL_SHARED_FOLDER_PATH 값을 채워 넣으세요 (예: \\SERVER\공용\검사결과). 안내 문구 표시용이며, 실제 저장 권한은 관리자 패널의 버튼으로만 부여됩니다.

8. 카운터로 자동 이메일 알림은 EmailJS 무료 계정을 만들고 EMAILJS_PUBLIC_KEY, EMAILJS_SERVICE_ID, EMAILJS_TEMPLATE_ID, COUNTER_EMAIL 값을 채워야 동작합니다 (인터넷 연결 필요). 템플릿에는 {{test_name}}, {{patient_info}}, {{total_score}}, {{severity}}, {{datetime}}, {{detail}} 변수를 사용할 수 있습니다.

9. 관리자 비밀번호는 파일 안에 평문으로 저장되어 있어 완벽한 보안은 아니지만, 환자가 실수로 저장 설정을 건드리는 것을 막는 용도로는 충분합니다.

10. 모바일(스마트폰·태블릿)에서 사용하기: 화면 자체는 스마트폰·태블릿 브라우저에서도 정상적으로 표시되고 검사 진행에는 문제가 없습니다. 다만 "공용 폴더 자동저장" 기능(폴더를 한 번 지정해두면 계속 저장되는 방식)은 안드로이드·iOS의 모바일 브라우저에서는 지원되지 않는 기능이라 모바일에서는 대신 결과 파일이 기기에 그냥 다운로드됩니다(휴대폰의 다운로드 폴더 등). 카운터 자동 이메일 알림은 모바일에서도 정상적으로 동작합니다. 그래서 병원 공용 폴더에 결과를 자동으로 모으는 용도로는 데스크톱의 Chrome 또는 Edge에서 실행하는 것을 권장하고, 모바일은 환자가 검사를 진행하는 용도로 쓰시는 것을 추천드립니다.
